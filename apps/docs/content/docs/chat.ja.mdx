チャットは、まだ明確なタスクになっていない作業に向いています。アイデアの整理、ワークスペースの状況確認、方針の議論、どのタスクにも属さない質問、あるいは小さな作業を先にエージェントに任せる、といった使い方です。

チャットはあなたと[エージェント](/agents)との一対一の会話で、[タスク](/issues)ボードの外にあります。会話全体は**完全に非公開**で、[ワークスペース](/workspaces)内のほかの人は、admin も含めて見ることができません。

チャットは**タスクに紐づきません**。エージェントはあなたのボードを見ておらず、タスクの説明やコメントを自動的には受け取らず、会話を勝手にタスクに変えることもしません。それでも権限の範囲内で Multica CLI を使い、ワークスペース、プロジェクト、タスク、スキルを照会できます。あなたが明示的に頼めば、あなたのワークスペース権限で代わりに操作します。たとえばタスクを作成できます。

チャットに背景を持たせることもできます。入力欄左下の **+** をクリックして**プロジェクトコンテキスト**を選ぶと、チャットに[プロジェクト](/projects)を紐づけられます。エージェントの実行時に、そのプロジェクトの説明やリポジトリなどのリソースが渡されます。

## チャットの開始

<Steps>
<Step>

サイドバーの**チャット**を開きます。

</Step>
<Step>

新規作成をクリックし、実行権限のあるエージェントを選択します。

</Step>
<Step>

メッセージを入力します。画像やファイルも添付できます。

</Step>
<Step>

送信すると、Multica はこのメッセージのための実行を作成し、返信は現在のチャットに戻ってきます。

</Step>
</Steps>

ランタイムがオフラインの場合、メッセージはオンラインに戻るまで待機します。エージェントがアーカイブされたり、あなたが実行権限を失ったりすると、新しいメッセージは送信できません。

最初のメッセージの前に、選択したエージェントに設定された候補が最大3件表示されます。選んでも完全なプロンプトが入力欄に入るだけで送信はされないので、先に手直しできます。候補が未設定のエージェントでは汎用の例が表示されます。

エージェントが返信したあと、その下に**フォローアップ質問**が表示されることがあります。クリックするとそのまま送信されます。

## どのページからでもチャットする

いま開いているページを離れずにチャットできます。ワークスペースの各ページの右下には丸いチャットボタンがあり（ツールチップは「Multica に質問」）、クリックするとフローティングチャットが開きます。このウィンドウとサイドバーの**チャット**ページは同じ会話を共有しているので、どちらで始めた会話も、もう一方で続けられます。

- `⌘J`（Windows と Linux では `Ctrl+J`）でフローティングチャットを開閉できます。開くとカーソルがメッセージ入力欄に入り、入力欄で文字を打っている最中でもこのキーで閉じられます。キーは**設定 → ショートカット**で変更できます。詳しくは[検索・ショートカット・環境設定](/shortcuts)を参照してください。
- ウィンドウは端をドラッグしてサイズを変えられるほか、展開や最小化もできます。エージェントが返信している間は、閉じた状態のチャットボタンが小さく脈打ちます。
- **チャット**ページ自体にはこのボタンが表示されず、`⌘J` も効きません。ページ全体ですでに同じ会話を表示しているためです。

フローティングチャットが不要なら、**設定 → 環境設定 → コメントとチャット**で**フローティングチャット**をオフにします。以後チャットはサイドバーからだけ開けます。この設定は今使っているデバイスにだけ適用されます。

## チャットとタスクの使い分け

| 目的 | 適した選択 |
|---|---|
| 手早い質問、方針の探索、個人的な下書き | **チャット** |
| 明確な担当者、ステータス、優先度、成果物 | **タスク** |
| チームメンバーが背景を確認して議論を続ける | **タスク** |
| 作業記録を残さずにワークスペースの情報を確認する | **チャット** |

Multica で作成したダイレクトチャットを読めるのは作成者だけで、ほかのメンバーや管理者は読めません。チームで見るべき結論は、タスク、プロジェクトの説明、またはスキルにまとめてください。

## マルチターンのコンテキスト

同じチャットは AI コーディングツール側の元のセッションを可能な限り継続するため、後続のメッセージで前の内容を繰り返す必要はありません。Multica はセッション ID を保存し、そのセッションにアクセスできるランタイムへ後続の実行をルーティングします。

ローカルのセッションがすでに存在しない、コンテキストを継続できない、直前のエラーを引き継ぐべきでない、といった場合、ランタイムは新しいセッションから開始します。チャットのメッセージ履歴はどちらの場合も保持されます。

## 実行の確認と停止

エージェントの実行中は、現在のフェーズとツールのアクティビティが画面に表示されます。**詳細を表示**を展開すると、より完全な実行過程を確認できます。エージェントがツール呼び出しの合間に書いたメッセージは、書かれた時点で会話に表示されるため、詳細を展開しなくても読めます。

中断するには、入力欄の横にある停止ボタン（入力欄が空のときに表示）をクリックします。すでにチャットへ返ってきた内容は保持されます。

エージェントがまだ何も出力していないうちに止めた場合、送ったばかりのメッセージは会話から取り下げられ、添付ファイルごと入力欄に戻るので、手直しして送り直せます。停止が完了するまで少し時間がかかることがありますが、その間にページを再読み込みしたりウィンドウを閉じたりしてもメッセージは失われず、次にその会話を開いたときに入力欄に戻ります。入力欄に別の下書きがある場合は、それを空にするまで待ちます。

## 返信中に続けてメッセージを送る

エージェントが返信している間も、次のメッセージを入力できます。入力欄に内容があると、送信ボタンは**キューに追加**に変わります。キューに入ったメッセージは今の返信を中断せず、入力欄の上のキューで待ち、返信が終わると順番に処理されます。

| 操作 | 結果 |
|---|---|
| **指示** | このメッセージを先頭に移し、今の返信を停止します。エージェントがすでに書いた内容は会話に残り、続けてこのメッセージを処理します。 |
| 削除（ゴミ箱アイコン） | メッセージをキューから外します。エージェントには送られません。 |
| **⋯ → キュー内のメッセージを編集** | メッセージを添付ファイルごと入力欄に戻します。直してから送り直せます。 |
| **⋯ → すべて削除** | キュー内のメッセージをすべて取り消します。今の返信はそのまま続きます。 |

今の返信が実際に始まるまで（たとえばランタイムに受け取られるのを待っている間）は**指示**を使えません。エージェントを実行する権限を失った場合も使えません。

## チャット一覧の整理

チャットは名前の変更、ピン留め、アーカイブ、削除ができます。

変更をまとめて承認する決定カードは、各項目に個別の**承認**と**却下**を表示します。カードを開いた時点では何も選ばれていません。ボタンは「Choose N more items」と表示され、すべての項目を選ぶまで無効です。選び終えると結果を示す表記(例:「Approve 2, Reject 1 with passkey」)に変わり、パスキー1回で承認した項目すべてをカバーします。送信後、各項目に結果(適用済み、または理由付きの未適用)が表示されます。

- **ピン留め**: よく使うチャットを一覧の先頭に固定します。
- **アーカイブ**: チャットを「アーカイブ済み」に移し、読み取り専用にします。
- **アーカイブ解除**: 再びメッセージを送信できるようになります。
- **削除**: チャットとその中のメッセージを完全に削除します。

これらの操作は、行の **⋯**（行にカーソルを重ねるか Tab で移動すると表示）または行の右クリックから開けます。行にフォーカスがある状態で `U` を押すと未読扱い、`P` でピン留め、`E` でアーカイブ、`R` で名前の変更ができます。入力欄に入力中や `⌘`・`Ctrl`・`Alt` を押している間は動作しません。

複数のチャットをまとめて操作するには、行にフォーカスして `X` を押すか、**複数選択** を選ぶか、スマートフォンでは行を長押しします。行にチェックを入れるか、日付の見出しにチェックを入れてそのグループ全体を選択し、下部のバーで **既読にする**、**ピン留め**、**アーカイブ** を使います。各ボタンは選択内容に合わせて変わり（たとえば選択した行の多くがピン留め済みなら **ピン留め解除**）、**▾** にはその逆の操作と対象のチャット数が表示されます。一括削除はありません。

チャットが外部チャネル（Slack など）に紐づいている場合、アーカイブすると紐づけは切断されます。アーカイブ解除では復元されないため、あらためて紐づけてください。

<Callout type="warning">
チャットの削除は元に戻せず、その中の未完了の実行も停止します。当面使わないだけならアーカイブしてください。
</Callout>

## 未対応の決定

エージェントがあなたの決定を待っている間、すべてのページに「N 件の決定が待っています」というチップが表示されます。チャット画面では同じ件数がヘッダーのボタンとして表示され、クリックすると未対応の決定が一覧になり、メッセージ一覧を動かさずに 1 件を開けます。他の画面ではチップをクリックすると最も古いものが開きます。決定カードのコメント位置の課題、カードにコメントがなければ課題そのものです。同じ決定は受信トレイと「Needs you」リストにも表示されます。選択肢を選ばず文章だけで答えてもカードは閉じ、エージェントはあなたの文章を読みます。

### 「Needs you」リストを片付ける

「Needs you」リストの各行には 2 つの操作があります。

- **完了** は行を対応済みにします。決定カードは完了にできません。回答してください。
- **後で** は、選んだ時刻まで行を非表示にします（既定は 2 時間、ICT で表示）。決定は開いたままで、リスト内の位置だけが後回しになります。

**すべて完了** は決定を除くすべての行を一度に完了にします。画面下のメッセージの **元に戻す** は 10 秒間使えます。

`/later [期間]` コマンドは、DM が「Needs you」に出しているものをまとめて後回しにします。期間は数字に `s`、`m`、`h`、`d` を付けたもので、1 秒から 7 日まで（既定は 2 時間）。エージェントには何も送信されません。

DM が未回答の質問を待っているとき、入力欄に「このメッセージは未回答の質問への返信です」のチェックボックスが表示されます。未回答が 1 件ならオン、複数ならオフで、オンにするとすべてに回答します。質問への回答でないメッセージは、質問を開いたままにします。
