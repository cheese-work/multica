description: DM 제목 짓기처럼 뒤에서 도는 작은 작업을 어떤 에이전트가 실행할지 고르고, 지정하지 않았을 때 어떻게 되는지 확인합니다.
---

뒤에서 이루어지는 작업이 있습니다. DM 제목 짓기, 퀵 액션 버튼 제안, 긴 DM 압축, 워크플로 단계 라우팅입니다. 이런 **백그라운드 작업**은 여러분이 고른 에이전트의 일반 태스크로 실행됩니다. 어떤 백그라운드 작업도 모델을 직접 호출하지 않습니다.

## 작업

| 작업 | 하는 일 | 설정할 수 있는 사람 |
|---|---|---|
| `dm_title` | 첫 메시지로 DM 제목을 짓습니다. | 워크스페이스 기본값, 또는 각 멤버가 자신의 DM에 대해 설정합니다. |
| `quick_actions` | DM에 퀵 액션 버튼을 제안합니다. | 워크스페이스 기본값, 또는 각 멤버. |
| `compact` | 긴 DM을 압축합니다. | 워크스페이스 기본값, 또는 각 멤버. |
| `routing` | 라우팅 전용 워크플로 단계를 맡습니다. | 워크스페이스 기본값만. |

각 작업에는 **기본** 에이전트와 선택 사항인 **대체** 에이전트가 있습니다.

## 작업을 실행하는 에이전트

작업이 트리거되면 Multica는 처음 일치하는 항목을 고릅니다.

1. 기본 에이전트를 설정했다면, 그 작업에 대한 **내 체인**.
2. 아니면 기본 에이전트가 있는 **워크스페이스 체인**.
3. 그것도 없으면 [에이전트 없음 경로](#에이전트가-실행되지-않을-때).

체인 안에서는 기본 에이전트가 먼저, 그다음 대체 에이전트가 실행됩니다. 설정되지 않았거나, 자격이 없거나, 보관되었거나, 연결할 수 없는 에이전트는 건너뜁니다. 대체 에이전트는 기본 에이전트의 실행이 제공자 오류로 실패했거나 기본 에이전트가 [제한 시간](#제한-시간)을 넘겼을 때만 실행됩니다. 장애 조치는 트리거당 한 번입니다.

내 체인이 있는데 그 안의 모든 에이전트가 실패하면, Multica는 워크스페이스 체인으로 넘어가지 않습니다. 명시적으로 고른 선택을 존중하여 에이전트 없음 경로가 실행됩니다.

## 에이전트가 실행되지 않을 때

에이전트가 지정되지 않았거나 쓸 수 있는 결과를 낸 에이전트가 없으면, 작업별 결과는 정해져 있습니다.

| 작업 | 에이전트 없음 동작 |
|---|---|
| `dm_title` | 첫 메시지에서 잘라낸 제목(60자). 모델 호출 없음. |
| `quick_actions` | 버튼 없음. 모델 호출 없음. |
| `compact` | 지금처럼 해당 DM의 에이전트가 압축합니다. |
| `routing` | 지금처럼 워크플로 단계의 담당 에이전트가 단계를 실행합니다. |

## 기존 워크스페이스 마이그레이션

제목이나 버튼 생성에 예전의 직접 모델 호출을 쓰는 워크스페이스라면, 직접 호출을 제거하는 빌드가 배포되기 **전에** 소유자가 `dm_title`과 `quick_actions` 에이전트를 설정해야 합니다. 그러지 않으면 제목은 60자 자르기로 돌아가고 버튼은 나타나지 않습니다. 이는 의도된 에이전트 없음 동작이며, 해당 워크스페이스에서는 눈에 보이는 변화입니다.

```bash
multica workspace background-agents set dm_title --agent <agent> --fallback <agent>
multica workspace background-agents set quick_actions --agent <agent>
```

## 제한 시간

제때 수락되지 않은 백그라운드 태스크는 취소되고, 너무 오래 걸린 실행은 실패 처리됩니다. 두 경우 모두 작업은 다음 슬롯으로 넘어갑니다.

| 작업 | 수락 제한 | 실행 제한 | 제한 초과 시 |
|---|---|---|---|
| `dm_title` | 10초 | 60초 | 다음 슬롯, 그다음 60자 제목. |
| `quick_actions` | 5초 | 20초 | 다음 슬롯, 그다음 버튼 없음. 자동 실행은 오류를 표시하지 않으며, 수동 새로고침은 지금처럼 실패를 알립니다. |
| `compact` | 30초 | 기존 압축 한도 | 지금처럼 DM의 에이전트가 압축합니다. |
| `routing` | 워크플로 단계 규칙 | 워크플로 단계 규칙 | 워크플로 단계 규칙. |

## CLI

워크스페이스 기본값을 확인하거나 설정합니다.

```bash
multica workspace background-agents list
multica workspace background-agents set dm_title --agent haiku --fallback luna
multica workspace background-agents set quick_actions --agent none
```

내 체인을 확인하거나 설정합니다.

```bash
multica me background-agents list
multica me background-agents set dm_title --agent haiku
multica me background-agents set dm_title --agent none   # 워크스페이스 기본값으로 되돌리기
```

- `<job>`은 `dm_title`, `quick_actions`, `compact`, `routing` 중 하나입니다. `multica me`는 앞의 셋만 받습니다.
- `--agent`와 `--fallback`은 에이전트 ID 또는 이름을 받습니다. `none`은 해당 필드를 지웁니다. 하나 이상 지정해야 합니다.
- `list`는 각 작업의 에이전트, 대체 에이전트, **출처**를 출력합니다. 출처는 `user`(내 체인), `workspace`, `off`(에이전트 없음 경로) 중 하나입니다. `--output json`은 같은 데이터를 JSON으로 출력합니다.
- 워크스페이스 기본값을 쓰려면 소유자 또는 관리자 권한이 필요합니다. 두 명령 모두 사람 전용이며, 태스크 토큰은 고정된 오류 코드와 함께 거부됩니다.
