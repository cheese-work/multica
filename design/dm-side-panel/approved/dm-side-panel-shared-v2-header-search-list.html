How v2 meets A, B and C

No direction dropped. The header is the same in all three; only the space under it differs.
  • A rail: header controls sit left of the Panel button. Search results overlay the chat column only; the rail stays. Phone: Panel button becomes icon plus count (frees 44 px).
  • B tabs: same as A. Stats stays in the header, not a tab: it is this DM's chat telemetry, not work state.
  • C strip: opening search replaces the chip strip until it closes, so the DM never shows two chrome rows plus results. Chip counts reappear on close.
  • Name clash to fix: panel "Cost today" (router L0 to L2 calls) vs header "Stats" (this DM's tokens and cost). Rename the panel row "Router cost today".
