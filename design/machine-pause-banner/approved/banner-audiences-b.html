B · One summary banner, header icon with a count · v1

The viewer gets at most one banner, above the page header. With one machine it reads like A (same words per audience). With several it states the count and the tasks that wait, and a Details control opens one row per machine inside the banner, each with its own Resume where the viewer may resume. One close control hides the banner for every event shown; a machine event that starts later shows it again, with a "New" tag on that row. The header icon carries a number: how many machines affect the viewer. Same icon place as A (right end of PageHeader). Left: desktop 780 px. Right: phone 390 px. Names, times and counts are sample data (ICT).
