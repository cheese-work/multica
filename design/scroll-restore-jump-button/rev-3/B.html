Native phone conflict (409 chat_compacting): not applicable

The native chat composer has no compacting state and no chat_compacting handling: apps/mobile/components/chat/chat-composer.tsx has only disabled and disabledReason, and apps/mobile/app/(app)/[workspace]/(tabs)/chat.tsx sets them for a missing agent or an archived session. No frame drawn. Disposition for the independent reviewer.

Spec

  • Name: Jump to latest messages (aria-label, tooltip on hover/focus on desktop).
  • Size: 36 px on desktop (--button-height-lg), 44 px on a coarse pointer and on native.
  • Position: horizontally centered on the reading column, 12 px above the composer card, never inside the safe-area inset.
  • Motion: fade 120 ms; scroll is instant when prefers-reduced-motion is set.
  • No count badge (out of scope).
  • Empty DM: no messages, so no button. Copy “No messages yet / Send a message to start this DM with {agent}.” The composer stays enabled.
  • Load failed: role="alert" block with a visible Retry button; no jump button (no list to jump in). Retry shows aria-busy and keeps the skeleton frame from the loading state.
  • Jump failed (latest page did not load): the button stays visible and aria-busy while retrying; a role="alert" strip under the header carries a Retry button. Either control retries the same load.
  • Rev-2 contrast: button boundary (A and C) uses --muted-foreground (5.70:1 light, 7.15:1 dark against the page); focus ring uses --foreground (the --ring token is 2.54:1 on light). Measurements in NOTES.md.
  • Retry in progress: Retry is replaced by a disabled “Retrying…” button with a rotating arc (static here). The block or strip carries aria-busy="true"; the jump button gets aria-busy="true" and aria-disabled="true" with the arc in place of the arrow. Visible text says why: “Retry is off until this attempt ends.”
  • Retry size: 36 px on desktop in the block and in the strip; 44 px on a coarse pointer and on native.
  • Read-only: copy and disabled composer follow current code (archived-agent-banner.tsx, agent-access-revoked-banner.tsx, chat.json placeholders). The transcript stays readable, so the jump button stays. It sits 12 px above the whole bottom stack (banner and composer).
  • Conflict: a send refused with 409 chat_compacting shows the existing toast “This DM is compacting. Send again when it finishes.” The composer is disabled with the “Compacting…” placeholder and keeps the restored draft. Toast position is owned by <Toaster />; the build checks that it does not cover the jump button.
  • B: a 2 px --page-canvas ring surrounds the disc so its edge stays visible over a light user bubble in dark mode (measured 2.56:1 without it).
  • C: the arrow sits on an opaque 25 px --surface backing inside the translucent halo. Underlay measurements: contrast-check.html and NOTES.md.
