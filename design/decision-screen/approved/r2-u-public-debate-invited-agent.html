What you see

  • The public banner stays on top. The member strip shows who is in the debate, like a group DM.
  • Typing @ lists agents not yet in the debate, each with a cost hint "≈ 1 run". Already-members are greyed.
  • An invited agent gets one tag, "invited by you" or "invited by the asking agent".
  • Replies that mention no one start no run.

Components, tokens, i18n

  • packages/views/chat/floating-chat.tsx shell; member popover reuses the mention picker (paths from the issue, not read from a checkout)
  • Tokens --open-bg for the cost tag, --info-bg for the invited tag
  • i18n decisions.debate.members, .invite_cost, .invited_by, .runs_started
  • Build default: mentions start runs only for the named agents; the assignee and squad leader do not wake (CHE-5481 comment 01a1d606-b74d-7c0a-b37b-e3ef3cd75d5b).

States and motion

  • Invite pending (agent not yet replied), agent failed to start (banner with Retry), already a member.
  • Member tag fades in 150 ms. prefers-reduced-motion: appears at once.
  • Focus: 2 px outline, 2 px offset, token --info, on every control; keyboard order follows reading order.
