What you see

  • Four fixed columns in one fixed order for every option: action → affects → reversible → metric.
  • Reversible is the only coloured node. Not reversible is red, Yes is green, on both options.
  • A missing field is a dashed "Not filled by agent" node, never a guess.
  • No star, ranking or "recommended" mark anywhere on the graph.

Components, tokens, i18n

  • New decision-consequence-graph.tsx inside decision-request-card.tsx; fields action, affects[], reversible, metric from the request payload (paths from the issue, not read from a checkout)
  • Tokens --ok-bg --no-bg --surface-border
  • i18n decisions.graph.action, .affects, .reversible, .metric, .not_filled

States and motion

  • Filled, partly filled, none filled (graph hidden, one line "No consequence fields").
  • Phone: one option per card, swipe-free, 44 px chips; graph reads top to bottom.
  • No animation. prefers-reduced-motion: n/a.
  • Graph text alternative: each graph is one image with a sentence naming action, affects, reversible and metric.
  • Focus: 2 px outline, 2 px offset, token --info, on every control; keyboard order follows reading order.
