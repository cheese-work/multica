(m) Draft annotation reopen · what you see

  • Today an unsent annotation note survives only until you select the same text again (useAnnotationNoteDraftStore, packages/views/issues/components/use-comment-annotations.tsx). New: a visible entry, N draft notes, in the issue header (A). Phone: same chip in the top bar, list opens as a bottom sheet.
  • The popover lists every kept draft: annotation notes (Reopen, Discard), the thread composer and the card "Other" box (Go to). Nothing sent or discarded stays in the list.
  • Reopen scrolls to the quoted text, highlights it and restores the note in its popover (B). Close keeps the draft. Send note or Discard removes it.
  • No drafts: no chip (C). Drafts survive reload and browse ↔ issue moves; the store is keyed by issue id, then by quoted range.

Components, tokens, i18n

  • Extend useAnnotationNoteDraftStore with a per-issue list selector; new packages/views/issues/components/draft-notes-entry.tsx. Composer and card "Other" drafts are read from their existing stores, not copied.
  • Tokens: --warning chip and quote rule, --surface-raised, --surface-border, --primary focus ring.
  • Keys: issues:drafts.count (plural), drafts.title, drafts.reopen, drafts.discard, drafts.keptHint. 6-locale parity.
  • Discard asks no confirm for a note under 20 chars; longer notes use an undo toast for 8 s. Chip and rows are real buttons with names; the popover traps focus and Esc closes it.
  • Focus: 2 px outline, 2 px offset, token --info, on every control; keyboard order follows reading order.
