C · One summary chip, hover popover with the modes inline in each agent row

One chip for any number of recipients, same as B. Hover opens one popover (openOnHover, safe polygon between chip and popover). Each agent is one row: avatar, name, and a four-way mode control with every mode visible at once. No second menu to travel to. The line under the rows shows the full description of the mode under the pointer or focus. Desktop: hover, 1 click, any count. iPhone: tap the chip, tap a mode: 2 taps, any count. The popover is anchored and non-modal (B uses a modal sheet on touch). Left: desktop, 900 px column of a 1440 px window. Right: iPhone Safari, 390 px, 40 px controls (a proposal). Names and states are sample data; today's states: frame "Ref · today's run-mode chip".
